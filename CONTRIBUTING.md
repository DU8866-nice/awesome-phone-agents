# 贡献指南 · Contributing

欢迎推荐项目、纠正错误或补充说明。English version below.

## 怎么提交

- **推荐项目**：[提交 Issue](https://github.com/DU8866-nice/awesome-phone-agents/issues/new/choose)，写上仓库地址、支持安卓还是 iPhone 和一句话说明。
- **直接改**：编辑 [`data/tools.yaml`](data/tools.yaml)，把条目加到合适的分类里，然后提 PR。README 由 `scripts/build_readme.py` 生成，请不要直接改 README。

每个条目需要：

```yaml
- repo: owner/name
  zh: "一句话中文说明：它做什么、适合什么场景。"
  en: "One-sentence English description."
  os: [android, ios]   # 可选：android、ios、harmony
  pc: true       # 可选：需要电脑（USB、ADB 或同一网络）
  local: true    # 可选：可用本地模型，屏幕内容不上传
  byok: true     # 可选：需要自备模型 API Key 或账号
  root: true     # 可选：需要 root 或越狱
  cn: true       # 可选：中文友好
```

本地预览：

```bash
pip install pyyaml
GITHUB_TOKEN=你的token python scripts/update_stats.py   # 可选，刷新星标
python scripts/build_readme.py
```

## 收录标准

- GitHub 上的开源项目，能让 AI 操作手机，或在手机上指挥 AI 编程助手，或帮开发者用 AI 测试手机 App。
- 能实际使用：有可安装的版本或清楚的使用说明。
- 说明要客观，写清楚支持安卓还是 iPhone、要不要电脑和 root、模型从哪来。
- 一年以上没有更新会标 💤，已归档的标 📦，链接失效的会移除。

不收录：

- 群控、养号、刷量、多账号营销工具；
- 绕过风控或反检测的“隐身”云手机；
- 抢红包、游戏外挂、自动薅羊毛类工具；
- 刷星、仿冒，或主要用来给付费服务导流的仓库。

## How to contribute

- **Suggest a project**: [open an issue](https://github.com/DU8866-nice/awesome-phone-agents/issues/new/choose) with the repository URL, whether it supports Android or iPhone, and one sentence about it.
- **Edit directly**: add an entry to [`data/tools.yaml`](data/tools.yaml) in the right category and open a PR. The README is generated by `scripts/build_readme.py`; please don't edit it by hand.

## What gets listed

- Open-source projects on GitHub that let AI operate a phone, steer AI coding agents from a phone, or help developers test mobile apps with AI.
- Usable: an installable release or clear instructions.
- Plain descriptions that say whether it supports Android or iPhone, whether it needs a computer or root, and where the model comes from.
- Projects with no update for over a year are marked 💤, archived ones 📦, and dead links are removed.

Not listed: phone farms, account farming, fake-engagement and multi-account marketing tools, "stealth" cloud phones built to evade detection, red-packet grabbers, game cheats and coupon bots, and repositories with fake stars, impersonation or that mainly funnel to a paid service.
